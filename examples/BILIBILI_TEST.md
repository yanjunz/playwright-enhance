## 🔧 故障排除

### 1. 浏览器未安装

```bash
playwright install chromium
```

### 2. 网络连接问题

**症状**：超时错误
```
❌ 错误: Timeout 30000ms exceeded
```

**解决**：
- 检查网络连接
- 确保可以访问 bilibili.com
- 使用 `--demo` 模式查看模拟数据

### 3. 页面元素定位失败

**症状**：找不到元素
```
❌ 错误: waiting for selector ".nav-search-input" failed
```

**原因**：B站页面结构可能变化

**解决**：
- 查看可见模式确认页面情况
- 联系维护者更新选择器
- 使用演示模式查看预期结果

### 4. 测试很慢

**正常**：首次测试较慢（浏览器启动、页面缓存）

**优化**：
- 使用无头模式（更快）
- 确保网络稳定
- 多次运行取平均值
